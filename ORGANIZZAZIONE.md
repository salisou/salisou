## Repository da considerare come archivio didattico

Il profilo contiene anche numerosi esercizi, demo e versioni di corsi creati in periodi diversi. Questi repository non vengono eliminati: devono essere trattati come **archivio storico** finché non viene verificato se esiste materiale utile da consolidare nei percorsi principali.

Esempi:

- vecchie edizioni di corsi Python
- vecchie edizioni di corsi SQL Server
- demo Blazor/ASP.NET
- esercizi C#, Python e SQL
- progetti Xamarin/.NET MAUI
- esercizi PHP/Symfony/Laravel
- piccoli progetti sperimentali

## Regola di organizzazione

Prima di archiviare o eliminare un repository:

1. verificare codice e README;
2. controllare se contiene materiale non presente nei repository principali;
3. identificare eventuali duplicati;
4. salvare o migrare il materiale utile;
5. solo dopo decidere se archiviarlo.

L'obiettivo è avere un GitHub leggibile professionalmente senza perdere il patrimonio didattico storico.
